# Harvey app icon — "La plume, encre et pierre" (H2·b)

A bordeaux fountain-pen nib coming out of a charcoal pen section, on a stone background.
The design rationale and the full decision path (15 explored options) live in the figcraft file,
page **Icône d'application** (frames *07 · Icône d'application* and *08 · Parcours de décision*,
master components in the *Composants maîtres* section).

Everything here is generated by `build_icon.py`. It is the single source for the geometry
(parameters at the top: nib, breather and slit, menu-bar glyph) and the colours (`APPEARANCES`).
Edit it and re-run:

```bash
python3 brand/icon/build_icon.py
```

Requires macOS `sips` and `iconutil`, plus ImageMagick `magick`.

## Files

| Path | Use |
|---|---|
| `layers/0-background.svg`, `1-nib.svg`, `2-section.svg` | Icon Composer layers, 1024 × 1024, full bleed (macOS 26 Tahoe applies the mask). Default appearance. |
| `layers/dark/*.svg` | The same layers with the Dark appearance's fills. |
| `preview/harvey-icon-{default,dark}.svg/-1024.png` | Flattened previews with the rounded-square mask. |
| `preview/harvey-icon-macos14.svg` | Classic grid (824 px body in 1024) used for the fallback `.icns`. |
| `Harvey.icns` | Fallback icon for macOS 14–15 (SPEC §8.2). |
| `menubar/harvey-menubar-template.svg`, `harvey-menubarTemplate(@2x).png` | Monochrome template image for the menu bar (black + alpha, 18 pt). |

## Layers and appearances

- **0 · Fond** — vertical stone gradient.
- **1 · Plume** — bordeaux body gradient, a darker shade facet on the right half, three fine
  engravings; the breather hole and slit are cut through, so the background shows in every
  appearance.
- **2 · Section** — charcoal pen section, horizontal gradient, thin light edge line.

The exact colours and opacities for Default and Dark are in `APPEARANCES` in `build_icon.py`
(and baked into `layers/` and `layers/dark/`). Tinted and Clear are derived by Icon Composer.
No shadow, glass or border is baked into any layer.

## Building the `.icon`

1. In Icon Composer (Xcode 26), create `Harvey.icon` and drop the three `layers/*.svg` files in
   order (0 at the back).
2. For the Dark appearance, use the fills from `layers/dark/`.
3. Save it as `brand/icon/Harvey.icon`; the release pipeline compiles it with `actool`
   into `Assets.car` (SPEC §8.2, §13).
